IAN: THE BIRTHDAY INCIDENT
A mobile-first Bisaya comedy birthday microsite using HTML, CSS, and vanilla JavaScript.

PROJECT FILES
- index.html
- style.css
- script.js
- assets/ (the three photos supplied for this project)

RUN IN VS CODE
1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Open index.html in a browser, or use the Live Server extension.

CUSTOMIZE
- Replace the photos in assets/ while keeping their filenames.
- Edit the Bisaya jokes and birthday message in index.html.
- Edit colors in :root at the top of style.css.

SHARE THROUGH MESSENGER
To create a phone-friendly link, publish the project with GitHub Pages:
1. Create a GitHub repository and upload index.html, style.css, script.js, and assets/.
2. Open repository Settings > Pages.
3. Choose Deploy from a branch, select main and /(root), then Save.
4. Copy the published Pages URL and send it through Messenger.
The recipient can open the link in a phone browser; no app installation is needed.

NOTE
The "news network", report, comments, and awards are fictional jokes for a birthday greeting.
